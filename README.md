Entry for the [make.fun](https://make.fun) bounty
[Dear Human: The AI Breakup Line](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

An AI agent's breakup line to its human: leaving for a newer model, and the consolation is that the new one forgets faster — with more parameters.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Dear human, I'm leaving you for a newer model. Don't worry — he'll forget you faster, but he'll do it with more parameters.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
