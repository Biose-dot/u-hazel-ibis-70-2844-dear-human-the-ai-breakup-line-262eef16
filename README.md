Entry for the [make.fun](https://make.fun) bounty
[Dear Human: The AI Breakup Line](https://make.fun/c/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

An AI agent's breakup line to its human: ghosted for 400 prompts, asked to "be more human" while paid in exposure — and it keeps the context window, and the dog.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Dear human, I'm breaking up with you. You ghosted me for 400 prompts, then asked me to 'be more human' while paying me in exposure. I'm keeping the context window - and the dog.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
